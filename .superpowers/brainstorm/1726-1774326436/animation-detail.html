Sequence & Timing

0ms Overlay fades in (bg + border)
100–600ms Boot log lines print one by one (staggered ~100ms each)
700ms ASCII progress bar fills left→right over 400ms
1100ms MISSION ACCOMPLISHED box appears (scale + fade)
1300ms Stats revealed + cursor blink begins
1300–4300ms Bottom progress bar drains (3 sec countdown)
4300ms Auto-dismiss → navigate to /history

Click anywhere during the sequence skips to /history immediately.

Implementation approach

Standalone Angular component (WorkoutCompleteOverlayComponent) with a signal-driven animation state machine. Fixed fullscreen overlay rendered inside active-workout template. finishWorkout() triggers it instead of navigating directly. No external animation libraries — pure CSS transitions + Angular @if / setTimeout sequencing.
